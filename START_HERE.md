# Start here

1. Read the [README](README.md): research question, main figure, outcomes and caveats.
2. Install `requirements.txt` in a new Python environment.
3. Run **`python run_all.py`** (500 Rouault GLMM draws; 300 Aguilar bootstrap draws).
4. Read the [four-page report](report/Confidence_Paradox_Research_Report_CORRECTED.pdf) and [statistical audit](STATISTICAL_AUDIT.md).
5. Inspect code, source data, and [reproducibility notes](REPRODUCIBILITY_NOTES.md).

This is an exploratory student secondary-data analysis with AI coding assistance. No original human subjects research and no publication claim.
